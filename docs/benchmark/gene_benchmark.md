# OrionGeno Gene Structure Benchmark

This page contains the gene-structure benchmark results for every species in the test set. The results are grouped by taxonomic group so you can compare tools within the same lineage.

- Dataset: `36` species from `16` taxonomic groups
- Tools compared: `OrionGeno`, `Tiberius`, `ANNEVO`, `Helixer`, `AUGUSTUS`, `Baseline`

> The tables include `CDS Sensitivity`, `CDS Precision`, `Exon F1`, `Gene Sensitivity`, `Gene Precision`, `Gene F1`, and `BUSCO`.
>
> `Baseline` only has a `BUSCO` score, so the other cells are left blank.
